# Kapela Noční Ozvěny

Web pro smyšlenou kapelu vytvořený jako samostatná práce PRG-05 a rozšířený o stránku Časté dotazy (PRG-SP1).

## Stránky
- `index.html` – úvod, o nás, termíny, kontakt
- `cenik.html` – ceník služeb a booking
- `galerie.html` – fotografie z koncertů
- `dotazy.html` – časté dotazy (FAQ)
- `admin.html` – správa termínů (localStorage)

## Obrázky
Fotografie z Unsplash (licence Unsplash License – free to use). Uloženy ve složce `obrazky/`.

## Spuštění
Otevřete `index.html` v prohlížeči nebo nasaďte na GitHub Pages.
